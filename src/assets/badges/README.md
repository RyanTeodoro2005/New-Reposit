# Certification artwork

Official badge artwork retrieved from the issuers' public Credly pages on 2026-09-22. See `sources.json` for the source pages and CDN URLs. Artwork belongs to the respective issuers; local copies keep the portfolio independent of third-party image availability.

The Notion Admin image is the certification's shared artwork, obtained from a public badge of the same type. That source is **not Ryan's credential** and must not be used as his verification link. Ryan's Admin qualification is listed in his provided CV; its verification URL remains unset.

Notion Service Specialist was verified on Ryan's public badge page, so its credential link is now available in all three languages.

The depth, full rotation and floating effect are implemented in CSS 3D. Each badge's original alpha channel masks its colored depth layers, preserving its individual silhouette without an added frame. Front and back faces use the unchanged artwork. Motion pauses outside the viewport, on hover/focus for readability, and with the site's motion toggle or reduced-motion preference.
